# Előfizetéskezelő – jogi oldalak

Ez a repó **kizárólag** az Előfizetéskezelő Android app publikus jogi dokumentumait (jelenleg:
adatvédelmi szabályzat) tartalmazza, GitHub Pages-en keresztül publikálva. Az app forráskódja
**nem** itt van, és nem is lesz — ez a repó szándékosan üres az app forrását illetően.

Élő oldal (GitHub Pages bekapcsolása után): `https://<felhasználónév>.github.io/<repónév>/`

## Frissítés

Az `index.html` fájl szerkesztése után `git push` — a GitHub Pages automatikusan újrapublikálja.
